## 📈 Мои проекты

Все проекты разработаны с нуля с акцентом на чистую архитектуру, модульность и расширяемость.

### 🤖 Telegram-боты

#### 🆘 HelpMe — Telegram-бот с анализом эмоций
Telegram-бот, который определяет эмоциональное состояние пользователя по тексту и подбирает поддерживающую цитату.

- Стек: Python, aiogram 3, aiosqlite, SQLite
- Что сделано: анализ эмоций по тексту, случайный подбор цитаты из БД через JOIN, inline-кнопки обратной связи, если не помогло — новая цитата.
- Ссылка: [helpme-bot](https://github.com/Lloydcodes25/helpme-bot)

#### 🌍 TranslationBot — Telegram-бот-переводчик
Telegram-бот для перевода слов между русским и английским языками с CRUD-операциями над словарём.

- Стек: Python, aiogram 3, aiosqlite, BotCommand
- Что сделано: перевод в обе стороны с автоопределением языка, добавление / обновление / удаление слов, нормализация ввода, встроенное меню команд.
- Ссылка: [translation-bot](https://github.com/Lloydcodes25/translation-bot)

#### 🧩 «Угадай загадку» — Telegram-бот-игра
Бот для игры в загадки с ограничением попыток и хранением данных в SQLite.

- Стек: Python, aiogram 3, aiosqlite, FSM
- Что сделано: 4 попытки на ответ, FSM-состояния, случайный выбор загадки из БД, счётчик попыток на пользователя.
- Ссылка: [riddle-game-bot](https://github.com/Lloydcodes25/riddle-game-bot)

### 💻 Консольные приложения

#### 🧮 NLP Calculator — Калькулятор на естественном языке
Калькулятор, который понимает математические выражения, сформулированные словами на русском и английском языках.

- Стек: Python, NLP, токенизация, обработка «грязного» ввода
- Что сделано: парсер, преобразующий фразы вида «сложи пять и три, потом умножь на десять» в валидные выражения. Обрабатывает смешанный ввод (русский + английский + цифры + знаки).
- Ссылка: [nlp-calculator](https://github.com/Lloydcodes25/nlp-calculator)

#### 📚 Librarian — Система управления знаниями с NLP
Консольное приложение для работы с базой знаний: книги, статьи, заметки. Понимает вопросы на естественном языке и обучается — запоминает новые определения, введённые пользователем.

- Стек: Python, NLP, JSON
- Что сделано: поиск определений по вопросу на естественном языке, обучение новым понятиям, сохранение данных между запусками, чёткое разделение слоёв.
- Ссылка: [librarian](https://github.com/Lloydcodes25/librarian)
